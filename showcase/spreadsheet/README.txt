📸 CARA MENGGANTI DENGAN SCREENSHOT ASLI KAMU:
------------------------------------------------------------------------
1. Ambil screenshot spreadsheet asli yang ingin kamu tampilkan.
2. Simpan gambar ke folder ini:
   P:\AntiGravity Project\LUNIX Porto Web\showcase\spreadsheet\

3. Kamu bisa menggunakan format .PNG atau .JPG / .WEBP.

4. Penamaan file yang direkomendasikan untuk proyek Payroll:
   - 01-input-payroll.png    -> Form input data pegawai & absensi
   - 02-formula-engine.png   -> Sheet rumus kalkulasi & logic otomatis
   - 03-dashboard-kpi.png    -> Visualisasi rekap / dashboard grafik
   - 04-slip-gaji.png        -> Template cetak slip gaji PDF
   - 05-bank-transfer.png    -> Format export file transfer bank (BCA/Mandiri)

5. Tips Resolusi Terbaik:
   - Resolusi ideal: 1920x1080 (16:9) atau rasio monitor standar.
   - Karena sudah dilengkapi fitur Zoom / Lightbox HD, pengunjung bisa
     memperbesar gambar hingga 300% dan menggeser layar (pan & drag).
   - Pastikan teks dan angka penting terlihat jelas dan tajam.
   - Gunakan data fiktif / samarkan data rahasia (privacy friendly).
