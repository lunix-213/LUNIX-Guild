# LUNIX — Guild Portfolio Web

Sebuah portofolio web interaktif bertema Guild Fantasi (*Guild Reception Hall & Interactive Entrance Experience*).

🌐 **Live Demo:** [https://lunix-213.github.io/](https://lunix-213.github.io/)

---

### ✨ Fitur Utama
1. **Interactive Guild Entrance:** Fasad gerbang dengan parallax kedalaman, pencahayaan realistis matahari/bulan, sistem waktu siang/malam, dan transisi buka-tutup pintu sinematik.
2. **Guild Reception Hall:** Meja resepsionis kayu walnut dengan maskot Lunix interaktif (dialog responsif, sapaan hangat, sound effects & BGM).
3. **Papan Pengumuman Quest:** Tumpukan lembaran misi kuno untuk menampilkan karya unggulan.
4. **Spreadsheet & Data Pipeline Showcase:** Preview interaktif formula, dashboard, dan integrasi enterprise.
5. **3D Web Showcase — McLaren:** Panggung showcase kendaraan 3D interaktif real-time berbasis WebGL ([Kunjungi](https://lunix-213.github.io/lunix-3d-webshowcase-mclaren/)).
6. **Live Attendance & Payroll Studio:** Sandbox mandiri client-side simulasi absensi & slip gaji enterprise via IndexedDB.
